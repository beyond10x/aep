# Limitations and trust assumptions

The current limitation list is the repository's
[gap register](https://github.com/beyond10x/aep/blob/main/docs/plan/gap-register.md).
Each row names the consequence and the evidence or decision that closes it; a gap leaves only by
code or explicit decision, never because a website paragraph was edited.

Accepted remediation work and its lifecycle state live in the
[planning store](https://github.com/beyond10x/aep/tree/main/.engineering/planning).
Designs that neither accepting surface has taken up remain proposals in the
[vision](https://github.com/beyond10x/aep/blob/main/docs/VISION.md#proposed-not-accepted).

For a release-by-release record of what changed, use the generated
[annotated-tag status](https://github.com/beyond10x/aep/blob/main/docs/status.md).
